# Experiment Lifecycle

Intended (not yet implemented) flow:

Investigation → Experiment definition → Run preparation → Environment capture → Execution →
Observation collection → Artifact generation → Analysis → Statistical evaluation →
Evidence registration → Reproduction → Conclusion

## Distinctions

| Concept | Meaning |
|---|---|
| Investigation | Group of related experiments answering a research question |
| Experiment | Reproducible definition: inputs, configuration, environment spec, procedure |
| Run | One concrete execution of an experiment under a specific configuration and seed |
| Observation | A measured result produced during a run |
| Artifact | A file or structured output generated by a run |
| Claim | A statement asserted about a system, resolving to a `ClaimStatus` |
| Evidence | Traceable observations, analyses, artifacts and provenance supporting or refuting a claim |

An experiment is a definition; runs instantiate it; observations and artifacts come from runs;
evidence is the curated, traceable link from those to a claim. A claim without evidence is a
hypothesis.
